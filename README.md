# Dwelluxe Landing

A polished static landing page template for a luxury real estate, interior design, or premium property launch brand.

## Getting started

Install dependencies and start the local development server:

```bash
npm install
npm run dev
```

Create a production build that outputs the static site to `build/`:

```bash
npm run build
```

For a quick syntax check of the JavaScript entry point, run:

```bash
npm run check
```

## Template sections

- Sticky responsive navigation
- Hero section with conversion-focused calls to action
- Featured publication logo strip
- Signature property cards
- Concierge service overview
- Testimonial panel
- Contact/consultation form mock interaction
